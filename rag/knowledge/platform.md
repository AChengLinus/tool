## 项目工具盒是什么（这个网站是干什么的）

项目工具盒（AChengLinus Tools）是华矩系列在线工具的统一入口，地址是 https://tool.acheng9616.com/ 。简单说，这个网站把 EL 裁剪、PR 数据处理、图片标记、电站仿真偏差分析这 4 个工具集中在一个页面，方便访客直接进入或下载。首页用卡片形式列出工具，点击卡片即可进入对应工具或下载入口。

## 首页的 4 个工具

1. **EL 裁剪** —— 太阳能电池板 EL（电致发光）照片自动裁剪，地址 https://el.acheng9616.com/
2. **PR 数据处理** —— 光伏电站 PR / PRstc 计算与报表导出，地址 https://pr.acheng9616.com/
3. **图片标记** —— 光伏组件 EL 点位标注工具（ELMarker），地址 https://pt.acheng9616.com/
4. **电站仿真偏差分析工具** —— HIL 实测与 PSCAD 仿真的偏差对比分析，地址 https://dat.acheng9616.com/

## 如何进入工具

- 打开首页后，在卡片区找到需要的工具，点击卡片下方的「进入工具 ↗」。
- **EL 裁剪**：点击后会先弹出「选择使用方式」，可选「服务器版（局域网）」或「下载离线版」。
- **电站仿真偏差分析工具**：点击后会弹出密码窗口，需要输入访问密码，该密码请向站长 AChengLinus 获取。
- 其余工具点击后直接在新标签页打开。

## 常见问题

### 页面打不开、一直转圈怎么办

先刷新页面；建议使用 Chrome、Edge 等现代浏览器。如果所在网络访问 GitHub Pages 较慢，可以稍等再试，或换一个网络环境。

### 手机上可以使用吗

首页和 PR 数据处理等网页工具在手机上可以打开，但 EL 裁剪、图片标记、电站仿真偏差分析涉及大图和批量处理，建议在电脑上使用。

### 这些工具会把我的数据上传吗

不会上传到第三方服务器：PR 数据处理完全在浏览器本地计算；EL 裁剪的服务器版运行在实验室局域网内（http://192.168.3.119:15789），离线版运行在本机；图片标记和电站仿真偏差分析是 Windows 桌面程序，数据留在本机。

### 忘记密码 / 没有访问密码

电站仿真偏差分析工具和 EL 裁剪的服务器版都有访问控制，密码由站长设置和分发，请通过 GitHub 联系 AChengLinus 获取，助手无法查看或重置密码。
