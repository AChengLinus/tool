## 图片标记是什么

图片标记（光伏组件 EL 点位标注工具 / ELMarker）用于在 EL 检测图上标注点位、缺陷或区域，并把标注结果导出成 CSV 用于统计和复核。提供 Windows 桌面版（Electron）和网页版，两者界面一致，网页版地址 https://pt.acheng9616.com/ 。

桌面版针对超大图片做了优化：几百 MB 到几 GB 的 16-bit TIFF 用「按需解码 + 分块瓦片」渲染，只解码屏幕可见区域，内存占用稳定，缩放平移流畅。网页版受浏览器画布上限限制，超大图建议用桌面版。

## 支持的文件

- TIFF（含 16-bit 灰度大图；网页版 ≤32MB 用内置解码，更大的自动走分块渲染）
- JPG / PNG / WebP 等常见位图
- PDF（按页渲染）
- DWG（检测到本机转换器时可打开）

## 操作步骤

1. 打开图片：菜单「文件 → 打开图片」，或页面上的打开按钮，也可以直接把文件拖进窗口。
2. 选择标注工具：点标注、框选、标注笔、框图、文字。
3. 选择颜色；在标记列表里「＋ 添加标记」可以新建颜色和名称，双击名称可重命名。
4. 在图上完成标注；用「抓手」移动图片、滚轮缩放，避免误加点。
5. 标注完成后导出 CSV；下次可导入 CSV 恢复标注。

## 工具栏说明

- **撤销 / 重做**：撤销上一步标注操作（Ctrl+Z）。
- **重置视图**：图片适应窗口大小。
- **清空**：清空当前图片的全部标注点。
- **关闭图片**：关闭当前图；有未导出的标注时会先确认。
- **抓手**：拖拽平移图片。
- **显示数字**：开关标注序号显示。
- **高清渲染**：加载后立即渲染当前视图的高清图，适合性能较好的电脑。
- **导出 CSV / 导入 CSV / 导出整图 / 导出窗口**。

## 超大图片的限制

- 瓦片模式下「导出整图」不可用（原始分辨率合成会超出内存），会提示改用「导出窗口」，即截取当前屏幕可见区域。
- 16-bit 灰度图按整图最小/最大亮度做对比度拉伸，避免 EL 图过暗看不清。
- 桌面版默认开启 GPU 加速；可在菜单「帮助 → 查看 GPU 加速状态」确认当前是否走显卡。

## 常见问题

### 打开几 GB 的 TIFF 就卡死或崩溃

网页版会尝试把整图解码到画布，几 GB 的 16-bit TIFF 会超出浏览器内存和画布上限。请改用桌面版，它会自动走瓦片渲染。

### 「导出整图」是灰色的 / 提示改用导出窗口

当前图片处于瓦片模式，无法合成原始分辨率整图。用「导出窗口」截取当前视图即可，或在桌面版里先缩小到可整图导出的尺寸。

### EL 图太暗看不清

16-bit 灰度会自动按整图 min/max 拉伸对比度；仍偏暗时可打开「高清渲染」，或确认原图本身曝光是否充足。

### 标注会丢吗

关闭图片或退出程序前，如果有未导出的标注会弹确认。建议养成先「导出 CSV」的习惯；下次用「导入 CSV」即可恢复标注。

### CSV 里是什么内容

导出的是每个标注点的位置、类型/颜色、文字等标注信息，可用于后续统计和复核；CSV 也能重新导入继续编辑。
